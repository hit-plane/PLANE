## 1. 项目概述与范围边界

### 1.1 项目概述

飞机大战是一款 2D 竖版单人飞行射击游戏：玩家操控战机在战场内移动，战机自动向上连续发射子弹，击毁从顶部不断生成并下压的敌机以获得分数，同时躲避敌机与敌弹；玩家拥有血量，血量归零则本局结束。击毁敌机可概率掉落道具，关卡随得分提升而加大敌机密度与高阶机型占比。主菜单提供战机与子弹的外观（皮肤）选择，并提供本局**难度选择**（简单/普通/困难，见 F21）。v1.2 起，道具改用贴图渲染（F18），关卡数上升时在战场中央显示**过渡动画**（F19），暂停时叠加**暂停界面**（F20），敌机血量随关卡成长（F22），玩家子弹伤害改为可配置项以便调平（F23）；战斗画面上方叠一条**信息带**，用经验条、生命心与火力图标呈现本关进度、剩余血量与当前火力（F25），主菜单的难度按钮组不带标题且始终居中（F26）。本说明书定义本期（Java 实训）开发范围内的功能与非功能需求，只描述"系统做什么、做到什么标准"，不描述界面布局与代码实现。

### 1.2 范围边界

**本期做（P0/P1）**：玩家移动与自动射击、四类敌机的生成与行为、碰撞检测与击毁、计分、玩家血量与受击、游戏结束、道具（含贴图）、难度关卡、暂停（含暂停界面）、最高分持久化、换肤、关卡过渡动画、可选难度、敌人血量随关卡成长、玩家子弹伤害可配置、**本局计时与通关最短用时记录**、**战斗信息带（经验条 / 生命心 / 火力图标）**、**主菜单难度区与窗口标题的呈现**。

**明确不做（P2，来源：客户材料 + Q5/Q8）**：联机对战与网战 PK、双人同机、移动平台、二段跳、地形障碍、天气影响弹道、友军 NPC、零件组装、武器合成、Boss 及多阶段 Boss、关卡编辑器、AI 自动玩。上述内容列入二期扩展，本期不投入开发。

> 实现现状与边界的偏差：敌机类型枚举保留了 `BOSS` 占位值（未生成、未渲染独立贴图）。处置待确认，见附录 E-2。

## 2. 术语表

| 术语 | 定义 |
| -- | -- |
| 战场 | 600×900 像素的竖版矩形游戏区域（宽 < 高），全文统一称"战场"，不使用"棋盘/网格/场地" |
| 玩家战机 | 玩家操控的己方飞机，开场位于战场底部中央 |
| 敌机 | 从战场顶部生成、向下运动的敌方飞机，分普通/横移/射击/自爆四类 |
| 玩家子弹 | 战机自动发射、向上飞行、用于击毁敌机的子弹 |
| 敌弹 | 射击类敌机发射、向下飞行、命中玩家会扣血的子弹 |
| 碰撞盒 | 用于判定两个实体是否接触的矩形区域 |
| 击毁 | 敌机累计受伤达到其血量后被销毁的过程 |
| 关卡 | 按累计得分划分的难度阶段，每 1000 分为 1 关，上限 10 关 |
| 道具 | 击毁敌机按概率掉落、玩家战机接触后获得增益的物体，分火力强化/全屏炸弹/护盾/回血四种 |
| 火力等级 | 单次射击发射的子弹发数，取值范围 1–5，等级 n 即 n 连发，等级越高弹幕越宽 |
| 无敌时间 | 玩家受击后短暂免疫伤害的时间窗口，本期为 1 秒 |
| 图标缩放 | 全局尺寸系数，取值 1.5；贴图渲染高度与碰撞盒同源同比放大，不出现"看得见却打不到" |
| 皮肤 | 玩家战机与玩家子弹的可选外观，各 4 种，在主菜单选择，不影响数值 |
| 难度 | 玩家开始一局前选择的本局强度档位，分简单/普通/困难三档；只在敌机血量、血量成长、道具掉落、敌机生成间隔、单机型刷新权重这**五个维度**上起作用，不影响玩家能力与敌机分值 |
| 难度倍率 | 难度档位对应的乘数，共**五个分量**（血量、血量成长、掉落、间隔、单机型刷新权重），普通档一律 1.0；逐档取值见下表 |
| 关卡倍率 | 敌机血量随关卡成长的乘数，等于 min(1 + 0.1 × (关卡 − 1), 3.0)；第 1 关为 1.0，第 10 关为 1.9 |
| 关卡过渡动画 | 关卡数上升时在战场中央显示的"第 N 关"横幅，总时长 1.5 秒；显示期间战斗照常进行，不冻结、不遮挡操作 |
| 道具贴图 | 道具的图片外观，四种道具各 1 张；贴图文件缺席时退回 v1.1 的"色块 + 文字"画法，程序不崩 |
| 通关 | 累计得分达到通关分数（10000）时的终局；**SRS v1.0 未定义该玩法，v1.1 标注为待确认，见附录 E-1** |
| 最高分 | 历史所有对局中得分最高的一局对应分数，关机后保留 |
| 用时 | 一局从开局到终局所消耗的时间，显示为 mm:ss.mm；**暂停期间不计时**，同一帧内先判死亡、再判通关，故阵亡帧的用时也有值 |
| 通关最短用时 | 某难度下所有已完成对局中通关最快的一局所对应的用时，关机后保留；按难度分别记录（附录 D-3） |
| 超时 | 用时达到计时上限（默认 1 小时）的状态；到达后不再计时，用时一律显示为"超时"，此时通关也记为"超时"而非具体用时 |
| 战斗信息带 | 战斗画面上方叠加的一条半透明横条，两行：第一行「第 N 关 / 经验条 / 本局用时」，第二行「生命心 / 火力图标」；本局进行的任何时刻都显示（F25） |
| 本关进度 | 当前得分在本关区间里所占的比例 = (累计得分 − 上一关阈值) ÷ 本关跨度，取值 0–100%；其分子是"本关已得的分" |
| 经验条 | 战斗信息带上表示本关进度的条状指示器，居中显示；两侧文字各贴着它的边缘往外摆（F25） |
| 生命心 | 战斗信息带上表示剩余血量的一组共 10 颗心形指示器，可为整颗/半颗/空，不足半颗的零头舍去；分母是"本档常规血量上限"——即不计作弊加成的上限，故作弊档血量超出常规上限的部分一律算满格（F25） |
| 火力图标 | 战斗信息带上表示当前火力等级的一组图标，火力几级就显示几个，右对齐（F25） |

> **难度倍率一览**（常规三列顺序为 简单 / 普通 / 困难；第四列「折磨」是隐藏档，需在主菜单输入暗号 `kskbl` 解锁。普通档五个分量全为 1.0，即旧版基准手感，各档曲线只是它的偏移）：

| 倍率分量 | 配置项 | 简单 | 普通 | 困难 | 折磨（隐藏） | 作用 |
| -- | -- | -- | -- | -- | -- | -- |
| 血量倍率 | `difficulty.*.enemy.health.mult` | 0.8 | 1.0 | 1.25 | 2.0 | 整条敌机血量曲线的起点 |
| 血量成长倍率 | `difficulty.*.enemy.health.growth.mult` | 0.7 | 1.0 | 1.5 | 2.5 | 每关血量成长率的快慢：越大后期涨得越陡 |
| 掉落倍率 | `difficulty.*.item.drop.rate.mult` | 1.4 | 1.0 | 0.8 | 0.5 | 道具掉落概率：越大掉得越多 |
| 间隔倍率 | `difficulty.*.spawn.interval.mult` | 1.2 | 1.0 | 0.8 | 0.6 | 敌机生成间隔：越大出得越稀疏 |
| 间隔下限 | `difficulty.*.spawn.interval.min` | 0.175 | 0.175 | 0.175 | 0.12 | 曲线乘完倍率后的地板；只有折磨档单独放宽 |
| 机型权重倍率 | `difficulty.<档>.type.weight.mult.<机型>` | 1.0 | 1.0 | 射击机 0.4，其余 1.0 | 全为 1.0 | 只改某一种机型出现的多寡，不改整体密度 |

> **四个要点**：① 掉落倍率乘在按关卡算完的掉落概率上，困难档第 1 关 40%、第 10 关 12%，**每一关都严格低于普通档**（普通档 50% / 15%），简单档 70% / 21%，折磨档 25% / 7.5%；② 生成间隔的**下限不乘倍率**，简单/普通/困难共用 0.175 秒（后期三档密度收敛到同一上限），**折磨档单独放宽到 0.12 秒**，因此它到后期仍比其它档更密；③ 机型权重倍率只压"会发射敌弹的射击机"：困难档第 2 关射击机占比 `0.4 / 5.4 ≈ 7.4%`（简单/普通档 `1 / 6 ≈ 16.7%`），第 5 关起权重封顶后 `1.6 / 12.6 ≈ 12.7%`（简单/普通档 `4 / 15 ≈ 26.7%`）。**注意总权重变小会让其余机型的占比被动抬高**（各自权重并未改动），例如困难档第 10 关自爆机占比由约 26.7% 升到约 31.6%；④ 折磨档不动任何机型权重——它要的是"什么敌机都来"。

> **作弊加成（作弊开关）**：暗号解锁后，主菜单出现「作弊」开关，**默认关闭**；**只有开启后**玩家才拿到下面四项加成，且**与所选难度无关**（四档都给同一套：难度只决定敌人多狠），**每一关开局都成立**（进下一关、重开一局走的是同一套复位逻辑）：

| 作弊加成 | 配置项 | 效果（四档相同） | 作弊关闭时 |
| -- | -- | -- | -- |
| 起始火力 | `difficulty.<档>.player.cheat.start.firepower` | +4 → 1 + 4 = **5 级**，开局即五连发（仍受 `player.firepower.max` 5 级封顶） | 1 级（单发） |
| 血量上限 | `difficulty.<档>.player.cheat.health.mult` | 99.99 → 100 × 99.99 = **9999**（另有"基准 × 100"的护栏，防手滑写天文数字） | 100 |
| 子弹速度 | `difficulty.<档>.player.cheat.bullet.speed.mult` | **2.0 倍** → 基线 3000 px/s 提到 6000 px/s | 基线 |
| 单发子弹伤害 | `difficulty.<档>.player.cheat.bullet.damage.mult` | **99.99** → 1 级 `100 × 99.99` = **9999**（一枪秒掉任何敌机；第 10 关最厚的射击机也才约 940 血）；5 级 `50 × 99.99` = 5000 | 常规伤害 |

> 伤害是在**乘完倍率之后**才取整的（1 级 100 × 99.99 = 9999、5 级 50 × 99.99 = 4999.5 → 5000），所以各火力档的百分比不会先把 9999 这个目标值四舍五入吃掉。

> 作弊关闭时，四档玩家侧一律是旧口径（单发、100 血、基线弹速、常规伤害），折磨档打开作弊前也只是"敌人更狠"。开关状态写在模型里，切换后立即重算玩家机（无需重开一局）。

## 4. 功能需求清单（F01–F26）

> **P0（F01–F09）覆盖完整流程：能开始 → 能进行 → 能结束。**

| 编号 | 功能 | 优先级 | 一句话说明 | 出处 |
| -- | -- | -- | -- | -- |
| F01 | 开始游戏 | P0 | 从主菜单进入一局：分数归零、玩家血量回满、火力等级复位、清空场上敌机/子弹/道具，战机回到战场底部中央 | 客户原文 ✅ |

| F08 | 计分 | P0 | 按敌机类型实时累加：普通 100、横移 150、射击 200、自爆 150 | 客户原文 ✅ + Q3 |

## 5. 用户故事（每个 P0 一段）

- **F01**：作为玩家，我希望从主菜单一键开始一局新游戏，以便每次都能从满血、零分的干净状态开始挑战。
- **F02**：作为玩家，我希望用键盘自由控制战机在战场内移动，以便躲避来袭的敌机和敌弹、占据有利射击位置。
- **F03**：作为玩家，我希望战机进入战斗后自动连续发射子弹，以便我专注于走位和躲避，不必分心反复按键开火。
- **F04**：作为玩家，我希望敌机不断从顶部随机位置出现，以便每一局面对的敌机排布都不同，保持挑战性。
- **F05**：作为玩家，我希望不同敌机有不同的下压和攻击方式，以便我能根据敌机类型判断威胁优先级、采取不同规避策略。
- **F06**：作为玩家，我希望子弹命中敌机后能逐步将其击毁，以便我的操作能得到明确、即时的反馈。
- **F07**：作为玩家，我希望战机有血量且受击后有短暂无敌时间，以便一次小失误不会被连续命中直接结束，操作更有容错。
- **F08**：作为玩家，我希望击毁不同敌机得到对应分数，以便通过分数量化我的战斗成果并追求更高纪录。
- **F09**：作为玩家，我希望血量耗尽时游戏明确结束并展示本局得分，以便我清楚本局结果并决定是否再来一局。
