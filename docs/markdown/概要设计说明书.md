## 1. 概述
本设计基于需求规格说明书 v1.0，采用 view/controller/model 三层架构。
设计目标：逻辑可脱离界面运行（可测试）、渲染可替换（可扩展）、开发可并行（接口解耦）。

## 2. 架构设计
（插入三层架构图）
依赖规则：View → Controller → Model，单向依赖，禁止反向调用。
Model 层零 JavaFX 引入，纯 Java 实现游戏逻辑。

## 3. 包结构设计
（插入包图 + 目录树）
| 包 | 核心职责 | 禁止行为 |
|----|----------|----------|
| view | 界面绘制、事件接收、画面渲染 | 编写游戏业务逻辑、存储游戏状态 |
| controller | 事件转发、流程调度 | 实现业务判断、直接操作实体状态 |
| model | 游戏状态、规则逻辑、碰撞判定 | 引入 JavaFX、依赖界面层组件 |

## 4. 类设计
（插入类图）
| 类/接口 | 所在包 | 一句话职责 | 依赖 |
|----------|--------|------------|------|
| GameView | view | 渲染画面、接收键盘事件 | GameController |
| GameController | controller | 转发事件、调度帧更新 | GameModel |
| GameModel | model | Model 层对外契约接口 | - |
| PlaneGameModel | model | 游戏逻辑核心实现 | PlayerPlane、Enemy、Bullet、Prop |
| PlayerPlane | model | 玩家飞机属性与行为 | - |
| Enemy | model | 敌机属性与行为 | - |
| Bullet | model | 子弹属性与移动 | - |
| Prop | model | 道具属性与效果 | - |
| ConsoleMain | model | 无界面运行验证 | GameModel |

## 8. 需求-设计跟踪矩阵
F01	游戏开始与重置	GameModel.start() 接口PlaneGameModel.start() 实现（初始化玩家飞机、清空实体列表、分数与生命值归零）	类图、时序图 2

F04	碰撞检测	PlaneGameModel.tick() 内碰撞检测逻辑包含：子弹 - 敌机、敌机 - 玩家、道具 - 玩家三类判定	时序图 2
F05	计分与生命值	PlaneGameModel.score 分数字段PlaneGameModel.lives 生命字段GameModel.getScore()/getLives() 读接口	时序图 2
F06	游戏结束判定	GameModel.isGameOver() 判定接口PlaneGameModel 生命值归零触发结束逻辑	时序图 2
F07	最高分持久化	[可延迟] Day07 实现 HighScoreStore 本地存储类当前版本不预留接口，不做过度设计	-
F08	难度递增	[可延迟] Day05 在 tick 中新增难度系数，动态调整敌机生成间隔与移动速度当前骨架兼容扩展	-
F09	暂停 / 恢复	[可延迟] Model 层新增 pause()/resume() 方法View 层转发窗口失焦 / 按键事件	-
F10	道具系统	Prop 道具实体类已预留[可延迟] 道具掉落、拾取效果逻辑 Day05 实现	类图
F11	多种敌机类型	Enemy 类预留 type 字段区分机型[可延迟] 不同机型的血量、速度、分值配置 Day05 实现	类图
F12	爆炸特效	[可延迟] View 层渲染爆炸动画Model 层标记爆炸状态与位置	-
F13	背景滚动	[可延迟] View 层实现背景滚动逻辑不侵入 Model 层核心规则	-
F14	音效系统	[可延迟] View 层新增音频播放模块对应事件触发播放	-
F15	游戏 UI 界面	[可延迟] View 层实现分数、生命值、开始 / 结束界面组件	-
F16	移动边界限制	PlaneGameModel 移动方法内的边界碰撞判定越界时位置不更新	时序图 1
