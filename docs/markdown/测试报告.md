## 4. 测试结论

1. **261 个用例全部通过**，无失败、无错误、无跳过，核心功能（启动、移动、射击、碰撞、计分、生命、道具、难度、最高分、暂停/重启、游戏结束、音效）均有断言覆盖；
2. 覆盖率数据来自 JaCoCo 工具真实输出，可在 `target/site/jacoco/index.html` 复现核验；
3. 已知边界：view 层覆盖率偏低，属 JavaFX 渲染代码难以纯单测覆盖的合理现象，已通过运行联调与兜底录屏补充验证。
