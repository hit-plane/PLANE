## 2. 关键优化说明

### OPT-01 窗口等比缩放
- 问题：高分屏/小屏下窗口内容显示不全，影响可玩性；
- 方案：启动时读取屏幕尺寸，按比例计算窗口与布局缩放；
- 效果：不同分辨率下均完整显示。

### OPT-05 受击特效与无敌帧
- 问题：玩家受击后缺少反馈，且可能连续掉血；
- 方案：受击闪白特效 + 受击后短时无敌窗口；
- 效果：打击反馈清晰，避免单次碰撞多次扣血。

### OPT-08 难度系统
- 问题：单一难度无挑战梯度；
- 方案：三档难度（easy/hard/torment），配置驱动生成间隔、敌机速度与分值；
- 效果：难度可选，最高分按档位隔离存储。
