# 飞机大战项目需求分析

## 一、项目概述

### 1.1 项目背景

本项目为 Java 课程实训/课程设计项目，基于 JavaFX 实现一款 2D 竖版飞行射击游戏（经典飞机大战模式）。项目以“核心玩法完整、扩展空间充足”为原则，覆盖 Java 面向对象编程、GUI 渲染、碰撞检测、状态管理等核心知识点，同时支持功能拓展与创意玩法实现。

### 1.2 项目目标

1. 实现经典飞机大战的核心玩法循环：玩家操控飞机移动射击 → 敌机生成与下落 → 碰撞判定与得分 → 道具拾取 → 难度递进 → 胜负判定。
2. 采用模块化架构设计，各功能解耦，便于后续迭代与功能扩展。
3. 输出完整可运行的 JavaFX 工程，具备基础的游戏界面、交互反馈与状态流转。

### 1.3 玩法梳理说明

对原始玩法描述进行了逻辑梳理与适配调整：

- 保留竖版射击的核心体验，将零散的玩法按系统分类，明确各模块的交互逻辑。
- 原始描述中“二段跳、移动平台”等更适配横版平台游戏的元素，调整为创意拓展选项，不纳入核心玩法。
- 对冲突/模糊的规则（如“掉血或者死”）进行明确：采用血量制，血量归零触发死亡。

## 二、核心玩法定义

玩家操控战机固定在屏幕下半区域，通过键盘或鼠标控制上下左右移动，同时自动（或按键）发射子弹；敌机从屏幕顶部随机生成，以不同模式向下移动，部分敌机会发射子弹。
玩家需要躲避敌机与敌方子弹，击毁敌机获得分数；击毁敌机有概率掉落道具，拾取后可增加一次性护盾、增加弹道数量、增加攻速、增加攻击力、清除全屏敌机、恢复血量等。
随着游戏进程推进，敌机数量、移速、攻击频率逐步提升，难度持续递增。玩家血量归零则游戏结束，最终以得分为胜负判定标准。

## 三、核心功能需求

### 3.1 玩家战机系统

| 功能点 | 详细说明                                                  |
| --- |-------------------------------------------------------|
| 移动控制 | 通过键盘方向键（WASD / 上下左右）和鼠标控制战机上下左右移动，移动范围限制在游戏窗口内，不可超出边界 |
| 射击机制 | 默认自动连续发射子弹，子弹从战机机头位置生成，沿竖直方向向上飞行，强化后弹道可呈集束状分叉         |
| 血量系统 | 玩家初始拥有固定血量值，被敌机子弹命中、与敌机碰撞均会扣除血量                       |
| 死亡判定 | 血量归零时触发游戏结束，冻结画面并显示最终得分                               |
| 无敌帧 | 受击后短暂进入无敌状态，避免连续扣血，提升操作容错性                            |

### 3.2 敌机系统

| 功能点 | 详细说明 |
| --- | --- |
| 基础敌机类型 | 1. 普通敌机：直线向下俯冲，血量低，移速中等，击毁得基础分   2. 横移敌机：左右摆动下落，血量低，移速稍快   3. 射击敌机：向下移动的同时发射子弹，血量中等，击毁得分更高   4. 自爆敌机：移速快，碰撞玩家造成高额伤害，自身销毁 |
| 生成规则 | 从屏幕顶部随机横坐标生成，按时间/得分逐步提升生成频率 |
| 离场判定 | 敌机飞出屏幕底部后自动销毁，不扣分 |

### 3.3 战斗与碰撞系统

| 功能点 | 详细说明 |
| --- | --- |
| 子弹碰撞 | 玩家子弹命中敌机时，扣除对应敌机血量；敌机血量归零后销毁，计入得分 |
| 机体碰撞 | 玩家战机与敌机发生接触时，玩家扣除血量，敌机销毁 |
| 敌方子弹 | 射击敌机发射的子弹向下飞行，命中玩家则扣除玩家血量 |
| 得分规则 | 不同类型敌机对应不同分值，击毁时实时累加分数 |

### 3.4 道具系统

| 道具类型 | 效果说明 |
| --- | --- |
| 火力强化 | 拾取后子弹数量增加（从单发变为双发/散弹），持续一段时间 |
| 全屏炸弹 | 拾取后立即清除屏幕上所有敌机与敌方子弹，获得对应得分 |
| 护盾道具 | 拾取后获得一层护盾，可抵挡一次伤害 |
| 血量恢复 | 拾取后回复一定数值的血量 |
| 其他道具 | 拾取后获得一次性护盾、增加弹道数量、增加攻速、增加攻击力、清除全屏敌机等 |


> 
> 道具掉落规则：击毁敌机或者按关卡进行时间按概率掉落，道具向下匀速移动，道具在底线闪烁3秒后消失，玩家战机接触即可拾取。

### 3.5 关卡与难度系统

1. 难度递进：以游戏时长/得分作为阈值，逐步提升敌机生成速度、增加高阶敌机占比、提升敌机移速与射击频率。
2. 关卡划分：可按得分分为多个关卡，每达到指定分数进入下一关，切换背景/生成新的敌机组合。
3. Boss 关卡（可选核心）：每达到特定分数出现 Boss 敌机，血量高、攻击模式多样，击毁后进入下一阶段。

### 3.6 UI 界面系统

| 界面 | 功能说明                             |
| --- |----------------------------------|
| 主菜单界面 | 显示游戏标题、“开始游戏”按钮、操作说明、排行榜、难度设置、关于 |
| 游戏内 HUD | 实时显示当前得分、剩余血量、当前火力等级             |
| 游戏结束界面 | 显示最终得分、“重新开始”按钮、“返回主菜单”按钮        |

## 四、扩展玩法设计（可选实现）

按实现难度与优先级分为三类，可根据开发进度选做：

### 4.1 进阶功能（推荐优先拓展）

- 连击系统：连续击毁敌机触发连击加成，短时间内无击毁则连击中断，连击越高得分倍率越高
- 僚机：拾取道具后生成小型僚机，跟随主机移动并辅助射击
- 武器类型：散弹、激光、穿透弹等不同子弹模式
- 背景滚动：自设背景动画，可修改，默认lwj的普通cg
- 存档功能：记录历史最高分，游戏启动时自动读取显示

### 4.2 创意拓展（可自选创新）

- 多种 Boss 阶段：Boss 具备多形态攻击，血量降低后切换攻击模式
- 陨石/流星障碍物：随机出现不可击毁的障碍物，仅可躲避
- 可破坏掩体：场景中出现掩体，可抵挡子弹但会被逐步击毁
- 能量槽大招：能量槽随时间/击杀积攒，满后可释放全屏清屏技能
- 震屏/慢动作：受击、释放炸弹时触发屏幕震动；关键时刻触发慢动作演出
- 音效系统：添加射击、爆炸、拾取道具、背景音乐等音效

### 4.3 创意玩法（脑洞拓展）

- 飞机升级系统：累计得分解锁不同机型，属性与初始火力不同
- 随机波次：每一波敌机的类型、数量随机生成，每局体验不同
- 双人同机：双人共用一台设备，分别控制移动与射击
- 天气系统：随机天气影响子弹速度与敌机移速
- 零件组装：击毁敌机掉落零件，可用于升级战机属性

### 4.4 通关奖励（脑洞拓展）
- 通关后强制播放lwj的特殊cg作为通关奖励

### 4.5 管理员模式（脑洞拓展）
- 可以通过管理员模式更简单通关游戏

## 五、非功能需求

1. **性能需求**：游戏帧率稳定在 60FPS 左右，无明显卡顿；碰撞检测精准，无穿透、误判问题。
2. **界面需求**：画面简洁清晰，元素辨识度高；UI 布局合理，关键信息（血量、得分）醒目。
3. **易用性**：操作逻辑符合常规认知，上手简单；游戏状态流转清晰，无卡死、无响应问题。
4. **可扩展性**：代码采用模块化分层设计（玩家、敌机、道具、工具类分离），新增敌机类型、道具类型无需修改核心逻辑。
5. **兼容性**：基于 JDK 17 + JavaFX 17 开发，支持 Windows 系统一键运行。
